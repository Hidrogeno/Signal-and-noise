# 005 Flocking:

Gif pending, work still in progress.

In this sketch we explore more robust physics arquitechture by renaming the particle class into Body, creating the Boid class and creating an animation in which several boids are created and start flocking around each other.

Work in progress, this sketch is not finalized.

Wind added, gives an additional force is a keyboard button is not pressed.

Added coloring in bands and waves to make more visually appealing.

## Concepts:
- Attraction, repulsion and direction correction
- Inheritance
- State depending rendering (size and color of the boids changes depending on their speed/interactions with each other)

## Controls:

Right now this is not interactive, but on further commits, the boids will interact with the mouse
